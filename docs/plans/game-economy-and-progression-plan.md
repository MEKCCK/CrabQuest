# Rust Learning Game：数值与新手节奏策划案

## 结论

游戏已经具备完整的奖励、挫败保护和通关循环；下一轮不应堆叠更多货币，而应先把现有机制的节奏和 55 关内容规模对齐。本方案以“完成一小段 Rust 学习后获得清晰反馈，但不会因连续失败被锁死”为目标。

两个必须先修正的结构性问题：

1. `rank_for()` 仍按旧的 15 关阈值封顶；现有主线已有 55 关，因此第 15 关后约 73% 的主线没有新的段位反馈。
2. 关卡按文件名排序；`54-l2-panics.toml` 会排在 `53-l4-boss.toml` 后，导致一个 L2 关被放在终章之后，破坏难度曲线。

本文件是策划与落地清单，不改变当前运行逻辑。

### 经济、挫败与解锁

| 机制 | 当前规则 | 观察 |
| --- | --- | --- |
| 普通关首次通过 | 25 XP | 一次制，重复通关 0 XP |
| 完美加成 | +10 XP | 首次通过且该关无失败；看提示不影响 XP |
| 连击加成 | +5 XP | 通过后的连击至少为 3；失败归零，重复通过仍会累加连击 |
| Boss 首通 | 4 次提交内 50 XP，之后 30 XP | 可再叠加完美与连击，单关上限 65 XP |
| 生命 | 初始 3，上限 5；普通失败 -1，通关 +1 | 0 心不可提交；阅读任一关说明每关每局可回 1 心 |
| Boss 挫败保护 | Boss 失败不扣心；失败满 5 次才允许提示 | 保护生命但提示门槛偏高 |
| 关卡解锁 | 线性解锁下一关 | 段位不参与主线解锁 |
| 自由模式 | 全主线通关后开启 | 所有关卡可重玩，重复通关不再发 XP |
| 成就 | 10 个，仅展示 | 不发 XP，避免和一次制 XP 相互干扰 |

当前 55 关的理论首通 XP 区间约为 **1,395–2,300**：下限按 51 个普通关各 25 XP、4 个 Boss 各 30 XP；上限按普通关 40 XP、Boss 65 XP。实际值取决于失败次数与连击。

## 目标体验与设计原则

1. 前 30 分钟必须让玩家经历“失败 → 看懂反馈 → 修复 → 解锁”的完整循环，且最多一次被 0 心拦住。
2. XP 只表达完成与成长，不作为解锁门槛；主线永远由学习顺序控制。
3. 普通失败是轻量摩擦，Boss 是高压但不消耗生命的综合检验；两者都不扣已得 XP，也不清空代码。
4. 提示是教学工具而不是收费项；越早期越早可用，Boss 的压力来自综合题而不是信息封锁。
5. 同一种“做对了”的奖励不应同时堆叠多个强数值。继续维持成就不发 XP，后续只增加徽章、边框、称号或统计页展示。

## 目标数值表

### XP 与连击

| 事件 | 目标值 | 规则 |
| --- | ---: | --- |
| 普通关首通 | 25 XP | 保持不变 |
| 无失败首通 | +10 XP | 保持不变；提示不扣 XP，以免压制求助行为 |
| 连击奖励 | +5 XP | 从第 3 个**首次通关**开始；重复通关不得抬升可奖励的连击 |
| Boss 首通（1–4 次提交） | 50 XP | 保持不变 |
| Boss 首通（5 次及以上） | 30 XP | 保持不变，保证尝试后仍有明确回报 |
| 重复通关 | 0 XP | 保持不变；在反馈中明确显示“练习完成，不重复发 XP” |

建议将连击定义为“连续的首次主线通关数”。当前重复通关会增加 combo，玩家可在已过关卡中预热连击后为下一关取得 +5 XP，既不符合连击直觉，也使数值展示失真。修正后，连续学习仍然有奖励，但不可刷。

### 生命与恢复

| 机制 | 目标值 | 适用阶段 |
| --- | ---: | --- |
| 初始生命 | 4 / 上限 5 | 新存档前 10 关；完成 L0 后自然沿用当前值，不再额外补满 |
| 普通失败 | -1，最低 0 | 全程 |
| 通关恢复 | +1，最高 5 | 全程 |
| 阅读说明恢复 | +1，每关每存档一次 | 全程；0 心提示必须直接指向可复习的已通关关卡 |
| Boss 失败 | 0 | 全程 |
| 0 心 | 禁止提交，允许编辑、提示和复习 | 全程 |

初始 4 心给新手一次额外的“读错错误信息”的空间；上限仍为 5，避免把失败成本完全抹掉。若不希望引入阶段性初始值字段，可先只把全局初始值从 3 调整为 4。

### 提示与参考答案

| 类型 | 目标解锁节奏 | 参考答案 |
| --- | --- | --- |
| L0 前 5 关 | 第 1 条默认可见；失败 1 次解锁定位；失败 2 次解锁修复思路 | 失败 3 次后二次确认展示 |
| 其余普通关 | 失败 0/1/3 次依次解锁概念、定位、修复思路 | 失败 4 次后二次确认展示 |
| Boss | 前 2 次失败仅反馈卡；第 3 次失败开放概念与定位；第 4 次开放修复思路 | 第 5 次后二次确认展示 |

所有正式关卡都应使用 `hints` + `hint_unlock`，而非只有少数高阶关拥有失败联动。提示查看继续零成本；“无师自通”成就仍可记录未看提示的高光表现，但不能把求助变成数值惩罚。

### Boss、奖励和解锁

| 项目 | 目标 |
| --- | --- |
| Boss 节奏 | 每个章节末 1 个；进入 Boss 前至少 1 关复盘/练习，Boss 后给 1 关低压巩固 |
| Boss 目标 | 验证本章节 2–3 个核心概念，不引入新语法，不以提示封锁制造难度 |
| Boss 奖励 | 现有 30/50 XP + Boss 徽章 + 章节完成卡；不追加可刷 XP |
| 章节完成 | 解锁下一章节、地图视觉升级、显示下一章节的学习目标 |
| 全通关 | 解锁自由模式、完整统计页、冠军徽章；保持重复通关 0 XP |

## 落地优先级

### P0：先恢复正确节奏

1. 将 `l2-panics` 放回 L2 的文件排序位置，或为关卡增加显式排序字段并迁移排序逻辑。
2. 用 55 关阈值替换旧 15 关 rank 表；统计页门槛和自由模式门槛同步验证。
3. 将 Boss/成就等判定始终从 `is_boss` 派生，避免关卡扩容后硬编码 ID 再次失效。

### P1：让挫败保护覆盖全主线

1. 为全部正式关补齐三级 `hints` 与对应 `hint_unlock`；按上表分层设阈值。
2. 把 Boss 提示门槛由 5 次失败调整为第 3 次开始分级开放。
3. 将初始生命提升至 4，并在 0 心状态提供可执行的复习入口。

### P2：清理奖励漏洞并强化反馈

1. 连击只由首次主线通关推进；复玩保持练习价值但不能预热 XP 连击。
2. 在通关面板固定展示“基础 / 完美 / 连击 / Boss”XP 明细和下一奖励节点。
3. 为章节完成、Boss 和自由模式增加不影响数值的徽章与地图视觉反馈。

## 验收指标

发布前至少进行 8–12 名目标用户试玩；若暂未接入遥测，使用试玩记录表逐局收集以下指标。

| 指标 | 目标 | 判定方式 |
| --- | --- | --- |
| 首关完成率 | ≥95% | 新玩家首次会话完成 00 关比例 |
| L0 完成率 | ≥80% | 首次会话或两次会话内完成前 10 关 |
| 首次 0 心出现位置 | 中位数不早于第 6 关 | 防止教程期过早惩罚 |
| 0 心后恢复成功率 | ≥90% | 玩家能通过复习回到可提交状态 |
| 普通关中位提交数 | 1–3 次 | 高于 3 需检查题面/错误卡/提示 |
| Boss 中位提交数 | 3–6 次 | 少于 2 说明无综合性；高于 7 说明提示或铺垫不足 |
| 提示使用率 | L0 20–45%，L1–L3 30–55% | 接近 0 表示不可见或羞辱性；过高表示题面不自洽 |
| 第 15 关后段位提升 | 每 5–8 关至少一次 | 确保扩容主线仍有成长反馈 |
| 重复通关 XP | 恒为 0 | 自动化回归 |
| 55 关顺序 | tier 不倒退 | 加载后按顺序断言 L0→L4，`l2-panics` 位于 L2 段 |

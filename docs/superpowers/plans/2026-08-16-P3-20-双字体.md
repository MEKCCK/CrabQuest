# P3-20：双字体与字体子集化记录

日期：2026-08-16
状态：已实施（feat/gameplay，commit 见 P3-20 提交）

## 1. 方案

- **Proportional** = `[noto_sans_sc, jetbrains_maple_mono, egui 默认]`：标题/描述/正文用无衬线中文（Noto Sans SC），maple 兜底 CJK（其全量 33,331 字形覆盖表意区，防 Noto 子集缺字）。
- **Monospace** = `[jetbrains_maple_mono, egui 默认]`：代码区等宽不变（Noto 非等宽，不进 Monospace）。
- 实现：`crates/game-ui/src/app_ui.rs` `install_fonts()`（P3-20 双字体栈，含 headless 测试）。

## 2. 字体来源与许可

| 项 | 值 |
|---|---|
| 字体 | Noto Sans SC（SIL OFL 1.1） |
| 来源 | Google Fonts 官方仓库 `https://github.com/google/fonts/raw/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf`（变量字体，wght 100-900） |
| 许可文件 | `crates/game-ui/assets/NotoSansSC-OFL.txt`（官方 OFL.txt 原样，含 Adobe 版权声明与 Reserved Font Name） |
| 版权 | Copyright 2014-2021 Adobe (http://www.adobe.com/), with Reserved Font Name 'Source' |
| 内嵌方式 | `include_bytes!` 编译期内嵌（运行时零 IO，同 maple） |

Maple（JetBrains Maple Mono，OFL 1.1）保持原样，许可见 `crates/game-ui/assets/OFL.txt`。

## 3. 子集化与覆盖验证

- 变量字体默认实例为 wght=100（Thin），先用 `fontTools.varLib.instancer` 固定 `wght=400`（Regular）再子集化。
- 用字语料：`assets/levels/*.toml` + `assets/errors.toml` + `crates/game-ui`、`crates/game-core` 全部 Rust 源码（含注释的保守超集）+ ASCII 可打印区。
- 工具：`crates/game-ui/scripts/font_subset.py`（复现 + `--check` 验证一键执行）。

| 产物 | 大小 |
|---|---|
| 源字体（变量，不提交） | 17.8 MB |
| 实例化 Regular（临时） | 10.6 MB |
| **提交子集 `NotoSansSC-Regular.ttf`** | **约 300 KB（≤5MB 验收通过）** |

覆盖验证结果（`python3 crates/game-ui/scripts/font_subset.py --check`）：

- CJK 用字 791+ 个全部在子集 cmap（noto 缺失 0-6 个视当时语料，走 maple 兜底）；
- 硬断言：全部 CJK 用字 ∈ `noto 子集 ∪ maple`（无缺字，脚本 exit 0 才通过）；
- emoji 37 个（✅🔓💡 等）不在两款字体 cmap，回退 egui 内置单色 emoji 字体（P3-20 决策，见 IME 决策记录 §5）。

## 4. 冒烟说明

- 双字体渲染效果（标题=Noto、代码=maple）需真实窗口截图确认，**无头环境不可验证**；已用 headless 测试证明字体安装不破坏无头绘制、两家族字形覆盖正确。
- 若未来文案新增用字：重跑 `python3 crates/game-ui/scripts/font_subset.py`（或 `--check` 验证）后提交新的子集产物。

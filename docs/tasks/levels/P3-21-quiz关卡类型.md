# 需求 P3-21：Quiz 关卡类型（选择题，复议）

- 优先级：P3（玩法，复议项）｜ 前置：P2-12（options/answer_index 字段）｜ 来源：v3 §4.3、§12.6

## 目标

复议并（若通过）落地选择题关卡类型（kind=quiz）：玩家从 2-6 个选项中选择代码运行结果。

## 背景（实测事实）

- rust-quiz 37 题实测：35 输出预测型（D1=21/D2=11/D3=3），其中部分适合选择题形式（如 013-mutable-zst，答案 `1`）。
- v3 §12.6 明确「v1 不引入选择题」；L2 结论：选择题判定（预测输出型/编译失败型/UB 型）与 compile→run→compare 流水线不兼容，需独立判定路径。
- P2-12 已在数据层加 options/answer_index（serde default，加载校验），交互层未实现。

## 需求范围（通过后执行；未通过则保持数据层支持、关卡 49 转输出比对关）

1. **判定流程**：quiz 关不提交代码、提交选项 → 比对 answer_index → 对/错；对 = 通关（XP 按 P1-05 普通关档），错 = 失败（hearts/combo 按普通关规则）。
2. **展示代码**：starter_code 在 quiz 关作为「展示代码」（须可编译可运行），玩家可运行预览（可选）但不编辑。
3. **选项校验**：2-6 项无重复、answer_index 界内（P2-12 已做加载校验，交互层复用）。
4. **难度映射**：仅 D1 题进第一版（013 需前置 recap）；D2/D3 不进。
5. **许可**：题代码可搬（CC BY-SA），选项文案与解释全部自写中文。

## 验收标准

- [ ] 选择题关可完成「选对 → 通关 + XP、选错 → 失败」闭环。
- [ ] 013-mutable-zst 作为首个 quiz 关落地（选项 `["0","1","编译错误","不确定"]`，答案 1）。
- [ ] 展示代码可编译（校验通过），玩家不可编辑。
- [ ] 选项越界/重复的数据在加载期报错（复用 P2-12 校验）。
- [ ] 未通过复议时：49 关转为输出比对关（不影响主线通关）。

# P4-26 自定义关卡导入：决策记录

> 需求：[gameplay/P4-26-自定义关卡导入](../gameplay/P4-26-自定义关卡导入.md)（T15）
> 设计：v3 §12.5（P4 自定义关卡导入）

## 决策 1：合并策略 —— 独立「自定义章节」（采纳需求文档建议）

**决定**：内置关卡与自定义关卡**不合并进同一条线性链**；自定义关卡独立成章，
地图页在「内置章节」下方新增「⭐ 自定义关卡」分区（仅当存在自定义关卡时显示）。

**理由**：

1. **进度/成就语义不混淆**：内置关卡是「线性解锁 + 段位/成就推进」的唯一来源；
   自定义关卡是自由挑战，若混入同一条链，会污染 `completed_count`/`champion`/`first_steps`
   等判定（成就/rank 语义以 v3 §7.3/§7.4 内置关卡为基准）。
2. **解锁链隔离**：自定义关卡全部默认 Unlocked（可直接挑战），不参与内置线性解锁链；
   内置章节末尾通关**不跨入**自定义章节（`Engine::next_in_chapter` 同章节推进）。
3. **错误隔离**：单文件校验失败只拒绝该文件，其余文件照常加载，游戏不崩溃。

**实现落点**：`Engine.level_set` 为「内置在前 + 自定义追加」的合并视图，
`Engine::builtin_count` 为分界下标；`ChapterMapData.custom_start` 供地图分区渲染。

## 决策 2：加载入口 —— `--levels <dir>` 覆盖默认用户目录（两者都支持）

**决定**：启动时扫描 `--levels <dir>`（`std::env::args` 解析，无 clap 依赖）；
未提供该参数时回退默认用户目录 `~/.local/share/rust-learning-game/levels/`。
目录不存在 = 无自定义关卡，行为与现状完全一致（不报错、不显示章节）。

**实现落点**：`game_data::custom_levels_dir_from_args(args)` +
`game_data::user_levels_dir()`；主程序在 `LevelSet::load` 成功后、构造 Engine 前调用
`game_core::load_custom_levels(dir, &builtin_ids)`。

## 决策 3：存档隔离 —— 进度可存，成就/rank 只认内置

**决定**：

- **可存**：自定义关卡进度照常写入 `save.level_states`（天然支持任意 id），
  通关标记 `"{custom_id}:pass"` 进 `completed_steps`；存档落盘/回读与内置一致。
- **不可触发**（成就/rank 侧）：
  - `Engine::builtin_completed_count()`：只数内置 id 中 `state == Passed` 的关卡，
    `rank_for()` 喂该计数（`rank_for` 签名不变）；
  - 成就检查只投喂「过滤掉自定义 id」的 `level_states`/`completed_steps` 快照，
    `total_levels` 用 `builtin_count`，自定义通关上下文不参与完美类成就判定；
  - **连击隔离**：自定义关卡通关不累加全局 combo、失败不重置 combo
    （combo_5/combo_10 不被自定义关卡刷/打断）。
- **共享但不越权**：XP、心数、活跃（streak）为全局游玩资源，自定义关卡照常参与
  （XP 不改变 rank 等级；心数/活跃是会话级体验，非进度元数据）。

**灰色地带（记录在案）**：`seen_error_codes`（error_collector 依据）是全局集合，
无法区分错误码来自内置还是自定义关卡，未做隔离——错误码是玩家真实见过的知识，
与「通关」类成就不同；如需严格隔离需新增存档字段，超出本任务范围，留作后续决策。

## 决策 4：错误反馈 —— 逐文件中文报错，双通道呈现

**决定**：单文件失败 → `CustomLevelError { file, reason }`，
启动日志 `eprintln!` 打印「自定义关卡 X 加载失败：原因」；同一份文案传入
`GameApp::with_custom_load_errors`，地图页顶部红色警示框呈现（游戏内提示）。
其余文件照常加载；id 与内置冲突、自定义集内重复 → 同样拒绝该文件并中文提示。

## 验收对照

- 外部目录 1 个合法关卡 → 加载进「自定义章节」并完整游玩（编译/输出比对/存档回读）✓（测试覆盖）
- id 与内置冲突 → 文件拒绝 + 中文提示，游戏正常启动 ✓（engine/app 测试 + 二进制冒烟）
- 非法 TOML / quiz 越界 / source 缺失 → 逐文件报错不崩溃 ✓（engine 测试）
- 自定义通关不触发成就/rank（champion 等仍按内置 15 关）✓（engine 测试）
- 无自定义目录 → 行为与现状一致（章节隐藏）✓（UI 测试）

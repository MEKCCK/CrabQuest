# 需求 P3-19：错误卡片行号跳转编辑器

- 优先级：P3（体验）｜ 前置：P1-03（ErrorCard 含 line）｜ 来源：v3 §7.7；docs-review/L3-C2-save-ui.md §2

## 目标

错误卡片「第 N 行」可点击，光标跳到编辑器对应行。

## 背景（实测事实）

- ErrorCard 已有 `line: Option<u32>`（解析器 --> 行号，P1-01/P1-03 产出）。
- 当前编辑器无 focus_line 状态，玩家需手动数行号定位错误。

## 需求范围

1. **focus_line 状态**：GameApp/UI 层新增 `focus_line: Option<usize>`；点击卡片行号 → 设置状态并切回编辑器屏幕。
2. **光标联动**：编辑器渲染时把光标（CCursorRange）移到 focus_line 对应行首；egui TextEdit 需用 `TextEdit::show` + 手动设置 cursor range 或等效机制。
3. **UI 呈现**：卡片行号以可点击样式（链接色/下划线）展示；focus 后反馈面板保持（底部固定区域）。
4. **边界**：line 超出代码行数 → 定位到文件末尾；无 line（EUNKNOWN 无 --> 行）→ 不渲染可点击行号。

## 验收标准

- [ ] 点击「第 N 行」→ 回到编辑器且光标在第 N 行（UI 状态断言）。
- [ ] line 为 None 的卡片不显示可点击行号。
- [ ] focus 后反馈面板不消失。
- [ ] 连续点击两个不同错误 → 光标正确切换。

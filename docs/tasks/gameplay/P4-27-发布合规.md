# 需求 P4-27：发布合规（许可/链接/版本矩阵）

- 优先级：P4（发布门槛）｜ 前置：P1-P3 全量 ｜ 来源：v3 §10、§11.1

## 目标

发布前合规审查：许可表全量核对、README 素材致谢、source/链接 CI 检查、rustc 版本矩阵验证「只比 E 码」策略不碎。

## 背景（实测事实）

- 许可事实（v3 §10.1 修正版）：rustlings **MIT only**（非 MIT/Apache）；rust-quiz CC BY-SA（解释须自写）；100-exercises CC BY-NC（禁商业）；rust-course **No License** 且 course.rs 已失效（404）；reference-cn 中文部分 Mulan PSL v2；字体 SIL OFL 1.1（OFL.txt 必修，P1-06）。
- 链接事实：doc.rust-lang.org/zh-CN 404 禁用；rustwiki.org 92 URL 实测 200 为白名单；course.rs 及其子域禁用。
- 版本风险：错误码语义稳定但措辞漂移，需版本矩阵验证（v3 §11.1「只比 E 码」策略）。

## 需求范围

1. **许可核对**：v3 §10.1 表逐行对照仓库实际 LICENSE 文件；README 新增「素材与许可」章节（全部来源 + rust-quiz CC BY-SA 提醒 + 100-exercises CC BY-NC 声明 + rust-course No License 声明与致谢联系渠道 + 字体 OFL 全文位置）。
2. **CI 检查**：
   - source 字段存在性 + 格式（正则）+ 与许可表一致（脚本）；
   - 链接白名单检查：errors.toml 与关卡 TOML 的 link/link_zh 域名白名单（rustwiki.org + doc.rust-lang.org/error_codes），发现 course.rs / doc.rust-lang.org/zh-CN 即失败；
   - 死码检查：errors.toml 活跃段不含 E0412/E0504（防回退）。
3. **版本矩阵（weekly job，非 PR 门禁）**：rustup 安装 rustc 1.8x / 1.9x 跑 Tier 2 fixture 矩阵，验证错误码与行号断言不碎；报告版本差异。
4. **分发门槛声明**：README 更新沙盒状态（bwrap 完成后去掉「开发期」字样）；确认 0 遗留「禁止公开分发」条件。

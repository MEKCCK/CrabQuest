# 需求 P4-26：自定义关卡导入

- 优先级：P4（玩法/发布）｜ 前置：P2-12（schema v2 校验）｜ 来源：v3 §12.5；docs-review/L1-plan.md 约束 11

## 目标

支持从外部 TOML 关卡目录加载自定义关卡，校验失败给出中文报错，不破坏内置关卡。

## 背景（实测事实）

- 设计文档计划②明确「自定义关卡导入（外部 TOML 关卡目录）」为 P4 内容。
- 内置关卡经 game-data 提供路径；自定义关卡需要独立加载路径 + 与内置关卡合并/隔离策略。

## 需求范围

1. **加载入口**：启动时扫描配置的额外关卡目录（如 `~/.local/share/rust-learning-game/levels/` 或启动参数 `--levels <dir>`）。
2. **校验**：复用 P2-12 加载校验（解析、quiz 合法性、hint_unlock 等长、source 存在性、id 唯一性——与内置关卡冲突时报错并拒绝加载该文件，不拖垮整个游戏）。
3. **合并策略**（决策项）：内置 + 自定义合并进同一地图（按文件名前缀排序）还是独立「自定义章节」——建议独立章节（避免与内置进度/成就语义混淆），决策记录写入文档。
4. **存档隔离**：自定义关卡进度可存（level_states 天然支持任意 id），但成就/rank 只按内置关卡判定。
5. **错误反馈**：单文件校验失败 → 启动日志 + 游戏内提示「自定义关卡 X 加载失败：原因」，其余文件正常加载。

## 验收标准

- [ ] 外部目录 1 个合法关卡可加载进「自定义章节」并正常游玩（编译/输出比对/存档）。
- [ ] id 与内置冲突 → 该文件拒绝加载 + 中文提示，游戏正常启动。
- [ ] 非法 TOML / quiz 越界 / source 缺失 → 逐文件报错不崩溃。
- [ ] 自定义关卡通关不触发成就/rank（champion 等仍按内置 53 关）。
- [ ] 无自定义目录时行为与现状一致（空章节不显示或隐藏入口）。

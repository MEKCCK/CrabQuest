# 需求 P2-11：Hint 与失败次数联动

- 优先级：P2（机制扩展）｜ 前置：无（机制已有手动逐级）｜ 来源：v3 §3.4、§7.6；docs-review/L3-C1-gamification.md §4.1

## 目标

提示按失败次数逐级解锁：0 次失败可看 hint1，随失败推进自动展开更高提示，≥4 次失败给参考答案（二次确认）。查看 hint 永远零成本。

## 背景（实测事实）

- 当前 hints 为手动逐级揭示（PR #1 实现，hint_step 步进），无失败联动。
- 防挫败设计核心：hint 是工具不是惩罚（不扣心/XP、不影响完美判定）。

## 需求范围

1. **联动行为表**（hint_unlock 语义落地）：
   | 失败次数 | 行为 |
   |---|---|
   | 0-1 | hint1 可看 |
   | ≥2 | hint1-2 解锁且自动展开 hint1 |
   | ≥3 | hint1-3 解锁且自动推进到 hint2 |
   | ≥4 | 推进到 hint3 + 「查看参考答案」按钮（二次确认「先自己试试？」） |
2. **数据模型**：`hint_unlock: Vec<u32>`（与 hints 等长，第 i 条在 attempts ≥ 阈值时解锁）；缺省 = 现状手动揭示（旧 TOML 零改动）。
3. **推进逻辑**：`attempts`（提交次数）达到阈值时自动展开到对应提示，不再需要手动按键逐级。
4. **参考答案按钮**：仅 ≥4 次失败出现，二次确认后才显示 hints[2] 修复代码。

## 验收标准

- [ ] 4 档行为表全部可测（构造 attempts=1/2/3/4 断言解锁状态与自动展开）。
- [ ] 手动揭示（hint_step 步进）在无 hint_unlock 字段时行为不变（旧关卡兼容）。
- [ ] 查看 hint 不扣心/XP、不影响完美通关判定（no_hint_perfect 成就仍看「是否看过」）。
- [ ] 参考答案二次确认弹窗可拒绝（拒绝后回到编辑不显示代码）。

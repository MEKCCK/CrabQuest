# 需求 P3-18：通关庆典与自由模式

- 优先级：P3（体验）｜ 前置：P1-04/05 ｜ 来源：v3 §7.7；docs-review/L3-C2-save-ui.md §4

## 目标

通关正反馈最小集（每项 ≤1 秒）+ 全通关一次性庆典 + R10 自由模式。

## 背景（实测事实）

- 当前通关反馈为「✅通关 + XP + 存档确认 + Enter 下一关」，无动画、无庆典、无自由模式。
- 防挫败与正反馈平衡：通关动画要快（≤1 秒），不拖节奏。

## 需求范围

1. **通关动画最小集**（顺序，每项 ≤1 秒）：XP 数字跳动 + ProgressBar 增长（+25 XP）→ 下一关标题 + 🔓 徽章 →「已自动保存」小字 + 首次显示存档路径 → hearts +1 提示 → Enter 进下一关 / Esc 回地图。
2. **末关庆典**：全部 15 关（扩展后 53 关）通关 →「🏆 全部通关！」一次性庆典；`victory_celebrated` 字段防重复（P1-04 存档已含）；庆典包含统计页入口。
3. **自由模式**：R10（铁锈冠军）解锁；`practice_unlock_all = true`（P1-04 存档已含）；地图所有关卡可重玩，无 XP 奖励（completed_steps 一次制天然支持）。
4. **统计页**（R9 解锁）：各关尝试次数、best_time_ms、hearts、成就进度展示。

## 验收标准

- [ ] 通关动画时序正确、总时长 ≤1 秒（UI 冒烟）。
- [ ] 末关通关出现庆典且只出现一次（victory_celebrated 防重，重启后不重复）。
- [ ] R10 前地图锁定逻辑不变；R10 后全部解锁且重复通关 +0 XP。
- [ ] best_time_ms 在通关分支记录（engine.submit Pass 分支）。

# 需求 P2-15：错误码解释卡片库

- 优先级：P2（内容生产）｜ 前置：P1-02（schema 字段）｜ 来源：v3 §6.2、§11.2；docs-review/L3-D2-pedagogy.md §2

## 目标

8 张高频错误码卡片精修入库，P0 全码补卡，为错误反馈面板提供「面向新手」解释内容。

## 背景（实测事实）

- L3-D2 已产出 8 张完整卡片草案（E0382/E0502/E0499/E0596/E0106/E0308/E0277/E0507），每张均用 rustc 1.97 `--edition 2021` 实测复现代码报错；修正了 E0507（i32 字段不报错 → String）与 E0596（原草案混 E0308）两处错误。
- 卡片代码在 docs-review/L3-D2-cards/（8 个 .rs 文件）。

## 需求范围

1. **8 张高频卡入库**：每张 = 一句话人话（≤30 字）+ 最小复现代码（≤12 行）+ 为什么错（≤60 字）+ 修复方向（≤40 字）+ 双链接（官方 + rustwiki）。
2. **P0 全码补卡**：现有关卡 6 码 + 新增 P0 5 码（E0282/E0384/E0594/E0621/E0601）+ EUNKNOWN 兜底卡，共 12 张基础卡。
3. **内容格式**：对齐 errors.toml schema v2 字段（zh/fix/example/concept/link/link_zh），直接进 errors.toml 或独立卡片表。
4. **措辞检查**：每卡过 §6.4 自查清单（术语基准、不逐句翻译、不复制 rust-quiz 解释）。

## 验收标准

- [ ] 每张卡片复现代码实际编译报对应错误码（rustc 实测命令记录）。
- [ ] 字数约束全部达标（脚本校验：人话 ≤30 / 为什么 ≤60 / 修复 ≤40 / 整卡 ≤200 汉字）。
- [ ] 链接实测 200（官方 + rustwiki 白名单）。
- [ ] 术语符合 §6.1 基准（无「生存期/特征/悬挂」等禁用词）。
- [ ] errors.toml 中对应条目 zh/fix/example 与卡片一致。

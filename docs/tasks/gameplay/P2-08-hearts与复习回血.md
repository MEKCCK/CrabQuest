# 需求 P2-08：Hearts 生命值与复习回血

- 优先级：P2（机制扩展）｜ 前置：P1-04（字段进存档）｜ 来源：v3 §7.4；docs-review/L3-C1-gamification.md §1.2

## 目标

引入 hearts（3-5）软惩罚机制：失败扣心、通关回血、0 心禁提交转复习引导；Boss 失败不扣心。

## 背景（实测事实）

- rust-quest hearts 机制（3-5，答错 −1 答对 +1，0 心强制学习）与编译校验型游戏语义需映射：本游戏「失败」= 提交未通过（编译错/输出不符/panic）。
- 防挫败原则：惩罚落在 hearts 与 combo（可恢复），不扣已得 XP、不重置代码。

## 需求范围

1. **规则**：初始 3、上限 5；提交失败 −1（floor 0）、通关 +1（cap 5）、复习回血 +1（心 <5 且每关每局一次，记 `"{level_id}:lore"`）、Boss 失败 0 扣。
2. **0 心禁提交**：提交按钮置灰 +「❤️ 已空：复习关卡说明可回 1 心」；不禁止编辑、不扣 XP。
3. **复习回血**：新增 `engine.review_lore(level_id)`，幂等（completed_steps 的 `"{id}:lore"` 标记）。
4. **存档**：hearts 字段（P1-04 已含），迁移显式补 3。

## 验收标准

- [ ] 初始 3；失败 3 次 → 0 心禁提交；通关 +1 至 cap 5。
- [ ] review_lore 幂等：同一关同局只回 1 次血。
- [ ] Boss 关失败 hearts 不变。
- [ ] 0 心时提交按钮禁用、提示文案正确；编辑仍可用。
- [ ] 纯逻辑单测覆盖增减边界（v3 §11.4）。

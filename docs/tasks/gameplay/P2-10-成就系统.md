# 需求 P2-10：成就系统（10 个）

- 优先级：P2（机制扩展）｜ 前置：P1-05（submit 钩子）｜ 来源：v3 §7.4；docs-review/L3-C1-gamification.md §2.3

## 目标

10 个静态成就，触发点挂 engine.submit 的 Pass/Fail 分支，HashSet 存档，无 XP 奖励。

## 背景（实测事实）

- 成就需要 seen_error_codes（累计见过 ≥10 种不同错误码）字段——P1-04 存档草案未含，需补充 `#[serde(default)]`。
- 成就纯展示（无 XP），避免与 XP 定价耦合。

## 需求范围

1. **成就表（10 个）**：
   | id | 名称 | 触发条件 |
   |---|---|---|
   | first_steps | 初出茅庐 | 首次通关 |
   | no_hint_perfect | 无师自通 | 首次提交即通过且未看 hint |
   | combo_5 / combo_10 | 连击 5 / 10 | combo 达 5 / 10 |
   | owner_guard | 所有权卫士 | 完美通关 04-l1-move |
   | boss_slayer | 斩将 | 击败任意 Boss |
   | boss_all | 屠龙 | 击败全部 4 个 Boss |
   | error_collector | 错误收藏家 | 累计见过 ≥10 种不同错误码（seen_error_codes） |
   | never_give_up | 永不言弃 | 单关失败 ≥10 次后仍通过 |
   | champion | 冠军 | 全部 15 关通关 |
2. **机制**：静态表 + HashSet 存档；`check_achievements` 纯函数，触发点挂 engine.submit 分支。
3. **存档**：achievements 字段（P1-04 已含）+ seen_error_codes 补充字段。
4. **展示**：成就页/图鉴入口（R7 图鉴全量开放联动，见 P1-05 rank）。

## 验收标准

- [ ] 10 个成就触发条件逐条可测（§11.4 用例）；触发后重复不重复入账（HashSet 幂等）。
- [ ] seen_error_codes 在解析器输出错误码时记录，≥10 种解锁 error_collector。
- [ ] 存档 roundtrip 后成就保留。
- [ ] no_hint_perfect：看过 hint 后即使一次通过也不触发。
